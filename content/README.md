# content

เนื้อหาของเว็บสาธารณะที่แก้ได้โดยไม่ต้องแตะโค้ด (Markdown) — โหลดโดย `src/lib/content.ts`

| โฟลเดอร์ | หน้าเว็บ | หมายเหตุ |
|---|---|---|
| `pages/stingless-bee.md` | `/stingless-bee` ชันโรงขนเงิน | หน้าความรู้ (ดูด้านล่าง) · ห้ามมีราคา |
| `pages/honey.md` | `/honey` น้ำผึ้งชันโรง | ข้อความของเจ้าของฟาร์ม (ปรับคำเล็กน้อย) + แหล่งอ้างอิงแบบเชิงอรรถ `[^id]` ท้ายไฟล์ · ห้ามเขียนว่ารักษา/บำบัด/คุณสมบัติทางยา · ทุกข้อความสุขภาพต้องมีอ้างอิง |
| `pages/privacy.md` | `/privacy` นโยบายความเป็นส่วนตัว | ร่าง — ควรให้เจ้าของเว็บทบทวน |
| `learn/research.md` | `/learn/research` น้ำผึ้งชันโรงในงานวิจัย | ต้องอ้างอิงทุกข้อ ไม่อ้างว่ารักษา/ป้องกันโรค ([docs/09](../docs/09-research-notes.md)) · ห้ามมีคำว่าราคา |
| `training/*.md` | `/training/<ชื่อไฟล์>` หลักสูตรอบรม | frontmatter `title`, `summary`, `duration`, `priceThb`, `order` — ราคา/ระยะเวลาจริงแก้ที่ `/admin/settings#courses` |
| `photos/`, `products/` | — | ว่าง (รูปสินค้า/รูปรังอัปโหลดจากหลังบ้าน) |

## หน้าความรู้ (`pages/stingless-bee.md`, `pages/honey.md`)

- frontmatter `lead:` = ข้อความเปิดใต้ชื่อหน้า · หัวข้อ `##` ขึ้นเป็นสารบัญ "ในหน้านี้" ให้เอง (ตั้งแต่ 3 หัวข้อ)
- รูปหลักและแกลเลอรีกำหนดในหน้า (`src/pages/stingless-bee.astro`, `honey.astro`) จากรายการ `src/lib/learn-photos.ts`
- รูปประกอบตอนนี้เป็นรูปจาก Wikimedia Commons พร้อมเครดิต (ไม่ใช่รูปจากฟาร์ม) — เมื่อมีรูปจริงของฟาร์ม ให้เพิ่มใน `src/lib/learn-photos.ts` แล้วเปลี่ยนในหน้า
