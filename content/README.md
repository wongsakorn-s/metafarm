| `pages/honey.md` | `/honey` น้ำผึ้งชันโรง | ข้อความของเจ้าของฟาร์ม (ปรับคำเล็กน้อย) · ไม่แสดงแหล่งอ้างอิงบนหน้า (ที่มาอยู่ใน docs/09) · ห้ามเขียนว่ารักษา/บำบัด/คุณสมบัติทางยา · ข้อความสุขภาพใหม่ต้องมีที่มาบันทึกใน docs/09 |

## หน้าความรู้ (`pages/stingless-bee.md`, `pages/honey.md`)

- frontmatter `lead:` = ข้อความเปิดใต้ชื่อหน้า · หัวข้อ `##` ขึ้นเป็นสารบัญ "ในหน้านี้" ให้เอง (ตั้งแต่ 3 หัวข้อ)
- รูปหลักและแกลเลอรีกำหนดในหน้า (`src/pages/stingless-bee.astro`, `honey.astro`) จากรายการ `src/lib/learn-photos.ts`
- รูปประกอบตอนนี้เป็นรูปจาก Wikimedia Commons พร้อมเครดิต (ไม่ใช่รูปจากฟาร์ม) — เมื่อมีรูปจริงของฟาร์ม ให้เพิ่มใน `src/lib/learn-photos.ts` แล้วเปลี่ยนในหน้า
