# 📝 เนื้อหาเว็บไซต์ (Content Management)

โฟลเดอร์นี้จัดเก็บเนื้อหาที่เป็นข้อความบทความในรูปแบบ **Markdown (.md)** ซึ่งถูกประมวลผลและนำไปแสดงบนหน้าเว็บสาธารณะผ่านโมดูล `src/lib/content.ts`  
ผู้ดูแลหรือเจ้าของฟาร์มสามารถปรับปรุงข้อความได้โดยตรงโดยไม่ต้องแก้ไขโค้ดโปรแกรม

## ⚙️ รูปแบบ Frontmatter และการจัดหน้า

บทความรองรับการกำหนด Metadata ด้านบนสุดของไฟล์ (YAML Frontmatter):

```markdown
---
title: "หัวข้อบทความ"
lead: "ข้อความเกริ่นนำสั้น ๆ ที่จะแสดงใต้ชื่อบทความ"
order: 1
---

## หัวข้อย่อยระดับ 2 (จะถูกสร้างเป็นสารบัญ 'ในหน้านี้' อัตโนมัติเมื่อมีตั้งแต่ 3 หัวข้อขึ้นไป)
เนื้อหาบทความ...
```

### หลักสูตรอบรม (`content/training/*.md`)
รองรับฟิลด์เพิ่มเติมดังนี้:
* `title`: ชื่อหลักสูตร
* `summary`: สรุปย่อของหลักสูตร
* `duration`: ระยะเวลาอบรม (เช่น "1 วัน (09:00 - 16:00 น.)")
* `priceThb`: ราคาตัวอย่าง (ราคาจริงสามารถปรับเปลี่ยนได้ผ่านระบบหลังบ้านที่ `/admin/settings`)
* `order`: ลำดับการแสดงผล

## ⚠️ กฎสำคัญด้านความถูกต้องและความปลอดภัย

> [!IMPORTANT]
> 1. **กฎหมายโฆษณาอาหารและสรรพคุณสุขภาพ:**
>    * หน้าน้ำผึ้งและงานวิจัย **ห้ามระบุว่าน้ำผึ้งรักษา บำบัด หรือป้องกันโรคใด ๆ** และ **ห้ามใช้คำว่า "สรรพคุณทางยา"**
>    * ต้องระบุข้อความกำกับเสมอว่า **"น้ำผึ้งชันโรงเป็นอาหาร ไม่ใช่ยา"** และ **"ไม่ควรให้เด็กอายุต่ำกว่า 1 ปีรับประทาน"**
>    * ทุกข้อความที่กล่าวถึงสารอาหารหรือประโยชน์ทางสุขภาพต้องมีแหล่งอ้างอิงทางวิชาการบันทึกไว้ใน [docs/09-research-notes.md](../docs/09-research-notes.md)
> 2. **การตรวจจับข้อมูลรั่วไหล (`bun run check:leaks`):**
>    * หน้าบทความ `/stingless-bee` และ `/learn/research` **ห้ามมีคำว่า "ราคา" หรือตัวเลขราคา** ระบบสแกนจะบล็อกหากพบข้อมูลราคาในหน้านี้
> 3. **รูปภาพประกอบ:**
>    * รูปภาพจริงของฟาร์มจะเก็บใน `public/photos/farm/` เป็นไฟล์ `.webp` ที่ลบข้อมูลพิกัด GPS/EXIF แล้ว
>    * ภาพจาก Wikimedia Commons ต้องแสดงเครดิตผู้ถ่ายและสัญญาอนุญาต (CC) ผ่านคอมโพเนนต์ `CreditPhoto` เสมอ
