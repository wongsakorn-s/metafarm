## วิเคราะห์จากคำตอบและข้อมูลจริง

### 1. ตอนนี้สินค้าหลักคือ "รังพันธุ์" ไม่ใช่น้ำผึ้ง

จากชีต "ขนเงิน":

| | จำนวน | มูลค่า |
|---|---|---|
| ซื้อรังเข้ามา | 52 รัง | 51,417 บาท (เฉลี่ยประมาณ 990 บาท/รัง) |
| ขายรังออก | 21 รัง | 32,450 บาท (**เฉลี่ย 1,545 บาท/รัง**, ช่วง 900–1,760) |
| ส่วนต่างสะสม | | −18,967 บาท |
| รังที่ยังอยู่ | 107 รัง | |

- **รายได้ทั้งหมดที่บันทึกไว้มาจากการขายรัง** ส่วนน้ำผึ้งยังไม่เคยบันทึกการเก็บ
- รังที่ขายออกเกือบทั้งหมดเป็นรังที่**ขยายหรือเพาะนางพญาเอง** แปลว่าฟาร์มมีความสามารถผลิตรังขายได้
- รังที่ยังอยู่ 107 รัง ถ้าขายได้ปีละ 20–30% ของรังที่ขยายได้ จะทำรายได้มากกว่าน้ำผึ้งในช่วงแรก

**ผลต่อการออกแบบ**
- หน้าแรกและเมนูสินค้าควรให้ **"รังสมบูรณ์"** เป็นสินค้าเด่น โดยดึงรายการจากรังที่ตั้งขายในหลังบ้านโดยตรง
- **สมุดพกชันโรง** ช่วยสร้างความน่าเชื่อถือ: ลูกค้าเห็นวันเกิดนางพญา รังแม่ และประวัติการแยกรัง ซึ่งผู้ขายรายอื่นไม่ค่อยมี
- หลังบ้านต้องทำให้การ**ตั้งขาย → ขายแล้ว**ง่ายที่สุด เพราะเป็นงานที่สร้างรายได้

### 2. สายพันธุ์รังมีพ่อแม่ 2 ทาง

รังที่เพาะเองบันทึกว่า "**ไข่นางจาก** A55" และ "**ไข่อ่อนจาก** A89" แยกกัน

→ data model ต้องมี `queen_source_hive_id` (แหล่งไข่นางพญา) และ `brood_source_hive_id` (แหล่งไข่อ่อน/ตัวงาน) แยกกัน ไม่ใช่ `parent_hive_id` ช่องเดียว
→ ใช้ข้อมูลนี้คำนวณได้ว่า **รังแม่ตัวไหนให้รังลูกที่รอดหรือขายได้มากที่สุด** ซึ่งช่วยเลือกรังแม่พันธุ์

### 3. อัตรารอดเป็นตัวชี้วัดสำคัญ

- รังล่ม 17 จาก 147 รัง (ประมาณ 12%) ส่วนใหญ่เป็นรังที่ซื้อมาช่วงแรก
- ควรมีแดชบอร์ดอัตรารอดแยกตามที่มา (ซื้อ / แยกรัง / เพาะนางพญา) และตามปี
- เพิ่มฟิลด์ "สาเหตุที่ล่ม" (ไม่บังคับกรอก) เพื่อเรียนรู้

### 4. ใช้คนเดียวและตรวจไม่บ่อย → หลังบ้านต้องเรียบง่าย

- **ไม่ทำ**ฟอร์มตรวจรังแบบละเอียด ใช้ "บันทึกเหตุการณ์" 5 ประเภทแทน: เก็บน้ำหวาน, เก็บไข่นางพญา, แยกไข่อ่อน/ตัวงาน, หมายเหตุ, เปลี่ยนสถานะ
- ในหน้ารายละเอียดรัง มีปุ่มลัดสำหรับแต่ละเหตุการณ์ที่กรอกได้ในไม่กี่วินาที
- ไม่ต้องมีระบบผู้ใช้ซับซ้อน แต่ทำตาราง `users` + role ไว้ตั้งแต่ต้น เพื่อเพิ่มคนได้โดยไม่ต้องแก้โครงสร้าง
- แทนช่องจำนวนจำกัดใน Excel (เก็บน้ำหวาน 6 ครั้ง, ไข่นางพญา 10 ครั้ง, แยกรัง 10 ครั้ง) ด้วยตารางเหตุการณ์ที่**ไม่จำกัดจำนวน**

### 5. น้ำผึ้งเพิ่งเริ่มบันทึก

- Excel ระบุว่า "ยังไม่เคย record ประวัติการเก็บน้ำหวาน" และตัวอย่างวันเก็บครั้งแรกคือ 10 ต.ค. 2569 (อีก 6 วันนับจากวันนี้)
- หน้าเก็บน้ำหวานควร**พร้อมใช้เร็วที่สุด** เพื่อไม่ต้องย้อนกรอกจากกระดาษ จนกว่าแอปจะพร้อม แนะนำให้จดลงแบบฟอร์มกระดาษหรือ Google Sheet ที่มีคอลัมน์ตรงกับ schema (รหัสรัง, วันที่, น้ำผึ้ง มล., ชัน กรัม, หมายเหตุ) เพื่อนำเข้าภายหลัง
- ชันโรงขนเงินเป็นชันโรงตัวเล็กและให้น้ำผึ้งต่อรังน้อย น้ำผึ้งจึงควรขายเป็น**ขวดเล็กราคาพรีเมียม** และระบุปีเก็บเกี่ยว ("น้ำผึ้งชันโรง ปี 2569") ตามที่เจ้าของฟาร์มร่างไว้

### 6. ราคาตัวอย่างรังเปล่า 690 บาท

ไฟล์ไม่มีราคารังเปล่า จึงประมาณจากข้อมูลที่มี:
- รังสมบูรณ์ขายเฉลี่ย 1,545 บาท ซึ่งรวมรังไม้สัก + ฝูงชันโรง + นางพญา
- รังเปล่าเป็นงานไม้สักทั้งหลังแบบ 2 ห้อง เคลือบโพลียูรีเทน มีต้นทุนวัสดุและค่าแรงสูงกว่ากล่องทั่วไป
- ตั้ง **690 บาท** (ประมาณ 45% ของราคารังสมบูรณ์) เป็นค่าตัวอย่างเพื่อทำหน้าเว็บ **ต้องให้เจ้าของฟาร์มคำนวณจากต้นทุนจริง**

### 7. งานวิจัยแทนการอ้างสรรพคุณ

- เนื้อหาเดิมเขียนว่าน้ำผึ้งฆ่าเซลล์มะเร็ง ป้องกันอัลไซเมอร์ และไม่ทำให้น้ำตาลพุ่งในผู้ป่วยเบาหวาน ซึ่งเป็นการอ้างรักษาหรือป้องกันโรค
- ร่างใหม่เล่าว่า**งานวิจัยพบอะไร ทดลองในระดับไหน** (ห้องแล็บ, เซลล์, สัตว์ หรือคน) พร้อมอ้างอิง และแยกออกจากหน้าขายสินค้า
- ข้อเสนอต่อยอด: **ส่งน้ำผึ้งของฟาร์มไปตรวจวิเคราะห์ที่แล็บ** (เช่น ความชื้น และปริมาณทรีฮาลูโลส) จะได้ข้อมูลจริงของสินค้าตัวเองมาใช้ ซึ่งน่าเชื่อถือกว่าอ้างงานวิจัยของชันโรงพันธุ์อื่น

### 8. ไฟล์รูปใน Excel

- สคริปต์นำเข้าจะดึงรูปออกมาตั้งชื่อตามรหัสรัง (เช่น `A25-1.jpg`) ใช้เป็นรูป 2 รูปของสมุดพก
- รูปใน Excel มักถูกย่อขนาดไว้ ถ้ามีไฟล์ต้นฉบับในมือถือหรือคอม ควรใช้ไฟล์ต้นฉบับแทนเพื่อความคมชัด
