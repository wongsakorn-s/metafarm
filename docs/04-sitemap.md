# Sitemap & หน้าจอ

ยึดเมนูจากชีต "โครงสร้าง Web App" ของเจ้าของฟาร์ม

## เว็บสาธารณะ

```
/                              หน้าแรก
/stingless-bee                 ชันโรงขนเงิน: ข้อความของเจ้าของ (ไฟล์ "ชันโรงขนเงิน R.1") 4 ส่วน — ผึ้งชันโรงคืออะไร · ชันโรงขนเงิน · โครงสร้างภายในรัง (รูปจริงพร้อมลูกศร) · รังชันโรงขนเงินของ MetaFarm (รูปจริง)
/honey                         น้ำผึ้งชันโรง: ข้อความของเจ้าของ + รูปจริงของฟาร์ม (ขวดหมี 3 ขวดข้างถ้วยน้ำหวาน) + ลิงก์ไป "น้ำผึ้งชันโรงในงานวิจัย" (ไม่มีแผงราคาแล้ว — ราคาอยู่ที่หน้าสินค้า)
```

### หน้าแรก
1. **Hero**: รูปสวนปาล์ม + รังไม้สัก, โลโก้ และประโยคหลัก เช่น "ชันโรงขนเงิน เลี้ยงในสวนปาล์ม ระยอง"
2. **เรื่องราว**: เริ่มเลี้ยงปี 2565, ลองหลายสายพันธุ์ แล้วพบว่าขนเงินเหมาะกับอากาศระยองที่สุด (จากชีต "หน้าแรก")
3. **รังไม้สักที่ออกแบบเอง**: จุดเด่นของแบรนด์
4. **ตัวเลขฟาร์ม** (ดึงจากฐานข้อมูล): จำนวนรังที่เลี้ยงอยู่, จำนวนรังที่เพาะนางพญาเอง, ปีที่เริ่มเลี้ยง
5. **สินค้าเด่น**: รังสมบูรณ์ที่ตั้งขาย 3–4 รัง และรังเปล่ากับน้ำผึ้ง
6. **วิดีโอแนะนำสวน** — คอลัมน์ขวาของส่วน "เรื่องราวของฟาร์ม" สูงเท่าฝั่งซ้าย (ซ้าย = เรื่องราว + จุดเด่น 3 ข้อ · มือถือเรียง เรื่องราว → วิดีโอ → จุดเด่น) (ไฟล์ที่อัปโหลดที่ `/admin/settings` หรือ YouTube · ไม่มีวิดีโอ = ไม่แสดงส่วนนี้) · ไฟล์เล่นผ่าน `/video/*`
7. **อบรม** + **สมุดพก** (อธิบายว่าทุกรังมีประวัติให้ตรวจสอบ)
8. **วิธีสั่งซื้อ**: ทัก LINE → โอน PromptPay → จัดส่ง/นัดรับ

ปุ่มติดต่อทุกหน้า: มือถือเป็นแถบล่างจอ (ช่องทางหลัก + ช่องทางอื่น) · คอมเป็นปุ่ม "ติดต่อเรา" มุมขวาล่าง — ตามช่องทางหลักที่เจ้าของเลือกใน `/admin/settings`

## หลังบ้าน (`/admin`)

ใช้ได้ทั้งมือถือและคอม: มือถือมีเมนูล่าง 5 แท็บ **ภาพรวม · รัง · บันทึก · ขาย · เมนู** (พนักงานเห็นแท็บ **ล็อต** แทน **ขาย**) ส่วนคอมใช้เมนูด้านข้างแบ่งกลุ่ม งานรัง / ขาย / เว็บไซต์และบัญชี

| กลุ่ม | หน้า | หมายเหตุ |
|---|---|---|
| **ภาพรวม** | `/admin` | ตัวเลขเดือนนี้เทียบเดือนก่อน (น้ำผึ้ง รังเพิ่ม ยอดขาย ออเดอร์ค้าง), กราฟ 12 เดือน, 5 รังน้ำผึ้งมากสุด, เหตุการณ์ล่าสุด |
| **งานรัง** | `/admin/hives` | ค้นหารหัส, ชิปกรองสถานะ, ตัวกรองเพิ่มเติม, เรียงตามคอลัมน์ |
| | `/admin/hives/:code` | ข้อมูล + ไทม์ไลน์ + บันทึก: **เก็บน้ำหวาน · เก็บไข่นาง · แยกรัง · หมายเหตุ · สถานะ/ตั้งขาย** (ลิงก์ตรง `?do=…#form-…`) |
| | `/admin/hives/:code/edit`, `/media` | แก้ข้อมูลรัง (รวมคู่ค้า 🔒 เจ้าของ/แอดมิน) · รูปสมุดพก 6 / รูปขาย 3 / วิดีโอ 1 |
| | `/admin/hives/new` | เพิ่มรัง (ตั้งรหัสเอง; ถ้าเลือก "แยกรังจาก" ระบบบันทึกในรังแม่ให้) |
| | `/admin/quick` | บันทึกด่วนจากหน้ารัง (จำชุดตัวอักษรรหัส) · `/admin/outbox` คิวรอส่งเมื่อสัญญาณไม่ดี |
| | `/admin/production` | ผลผลิต + สภาพอากาศ (NASA POWER) |
| | `/admin/photos`, `/admin/todo` | คิวถ่ายรูปรัง · ข้อมูลที่ยังไม่ครบ |
| **ขาย** 💰 | `/admin/orders` (+ `new`, `:code`), `/admin/customers` | ออเดอร์ / ลูกค้า |
| | `/admin/lots` (+ `new`, `:code`, `:code/labels`) | ล็อตน้ำผึ้ง บรรจุขวด พิมพ์ฉลาก QR (พนักงานเข้าได้ ไม่เห็นต้นทุน) |
| | `/admin/products`, `/admin/reports` | สินค้า/ราคา/สต็อก/รูป + เพิ่ม/ซ่อนขนาด + แก้ชื่อและคำอธิบาย + รูปหลายรูป (ลากเรียง) · รายงาน + CSV |
| **เว็บไซต์และบัญชี** | `/admin/readiness` 💰, `/admin/settings` 💰 | เตรียมเปิดเว็บ · ช่องทางติดต่อ, รูปหน้าแรก, การชำระเงิน, พิกัดฟาร์ม, ราคาอบรม |
| | `/admin/gallery` 💰 | รูปหน้าแกลเลอรี: อัปโหลดตามหมวด คำบรรยาย ลบ เรียงลำดับด้วยการลากวาง (จุดจับมุมรูป · เมาส์/นิ้ว/คีย์บอร์ด Space+ลูกศร · ไม่มี JS ใช้ปุ่มเลื่อนใน noscript) — ลำดับในหน้านี้ = ลำดับบนเว็บ รูปใหม่ขึ้นบนสุด · เข้าจากหน้า "เมนู" (`/admin/more`): มือถือ = แท็บล่าง "เมนู" · คอม = ลิงก์ "เมนู" ท้ายเมนูข้างซ้าย (หน้าเมนูบนคอมแบ่ง 2 คอลัมน์) |
| | `/admin/users` 👑 | ผู้ใช้และสิทธิ์: เพิ่มผู้ใช้, เปลี่ยนบทบาท, รีเซ็ตรหัส, ปิดบัญชี |
| | `/admin/account`, `/admin/more` | เปลี่ยนรหัสผ่าน · เมนูทั้งหมด (มือถือ) |

💰 = เจ้าของและแอดมินเท่านั้น · 👑 = เจ้าของเท่านั้น (ดู [12-phase5-plan.md](12-phase5-plan.md) ข้อ 5.1)
