# Sitemap & หน้าจอ

ยึดเมนูจากชีต "โครงสร้าง Web App" ของเจ้าของฟาร์ม

## เว็บสาธารณะ

```
/                              หน้าแรก
/stingless-bee                 ชันโรงขนเงิน (ความรู้ + โครงสร้างรัง)
/honey                         น้ำผึ้งชันโรง (+ ลิงก์ไป "น้ำผึ้งชันโรงในงานวิจัย")
/learn/research                น้ำผึ้งชันโรงในงานวิจัย (ไม่มีปุ่มขาย)
/products                      สินค้า
  /products/hives              รังสมบูรณ์ (ดึงจากรังที่ตั้ง for_sale)
  /products/hives/:code        รายละเอียดรังที่ขาย (รูป 2+3, วิดีโอ, ราคา, ประวัติ)
  /products/hive-box           รังเปล่า (รังไม้สัก 2 ห้อง)
  /products/honey              น้ำผึ้งชันโรง ปี 2569 (Size เล็ก / ใหญ่)
/training                      อบรม (หน้ารายละเอียด)
  /training/hive-splitting     อบรมการแยกขยายรัง
  /training/honey-processing   อบรมการกรองน้ำผึ้งและการแปรรูป
/passport                      สมุดพกชันโรง Metafarm (ค้นหาด้วยรหัสรัง)
  /passport/:code              สมุดพกของรัง (เปิดจาก QR ที่ติดรัง)
/contact                       ติดต่อเรา (LINE, โทร, Facebook, แผนที่ ต.หนองไร่ อ.ปลวกแดง จ.ระยอง)
/privacy                       นโยบายความเป็นส่วนตัว
```

### หน้าแรก
1. **Hero**: รูปสวนปาล์ม + รังไม้สัก, โลโก้ และประโยคหลัก เช่น "ชันโรงขนเงิน เลี้ยงในสวนปาล์ม ระยอง"
2. **เรื่องราว**: เริ่มเลี้ยงปี 2565, ลองหลายสายพันธุ์ แล้วพบว่าขนเงินเหมาะกับอากาศระยองที่สุด (จากชีต "หน้าแรก")
3. **รังไม้สักที่ออกแบบเอง**: จุดเด่นของแบรนด์
4. **ตัวเลขฟาร์ม** (ดึงจากฐานข้อมูล): จำนวนรังที่เลี้ยงอยู่, จำนวนรังที่เพาะนางพญาเอง, ปีที่เริ่มเลี้ยง
5. **สินค้าเด่น**: รังสมบูรณ์ที่ตั้งขาย 3–4 รัง และรังเปล่ากับน้ำผึ้ง
6. **วิดีโอแนะนำสวน** (YouTube)
7. **อบรม** + **สมุดพก** (อธิบายว่าทุกรังมีประวัติให้ตรวจสอบ)
8. **วิธีสั่งซื้อ**: ทัก LINE → โอน PromptPay → จัดส่ง/นัดรับ

ปุ่ม LINE ลอยมุมขวาล่างทุกหน้า

## หลังบ้าน (`/admin`)

ออกแบบให้**คนเดียวใช้บนมือถือ**ได้: เมนูด้านล่าง 4 แท็บ ส่วนบนคอมใช้เมนูด้านข้าง

| แท็บ | หน้า | หมายเหตุ |
|---|---|---|
| **ภาพรวม** | `/admin` | จำนวนรังตามสถานะ, รังที่ตั้งขาย, เหตุการณ์ล่าสุด, อัตรารอดตามที่มา |
| **รัง** | `/admin/hives` | ค้นหารหัส, กรองตามสถานะ/ที่มา/ขาย |
| | `/admin/hives/:code` | ข้อมูล + ไทม์ไลน์ + ปุ่มลัด: **เก็บน้ำหวาน · เก็บไข่นาง · แยกรัง · หมายเหตุ** |
| | `/admin/hives/new` | เพิ่มรัง (ถ้าเลือก "แยกรังจาก" ระบบจะสร้างเหตุการณ์ในรังแม่ให้อัตโนมัติ) |
| | `/admin/hives/:code/sale` | ตั้งขาย: ราคา, รูป 3 รูป, ลิงก์วิดีโอ |
| **ขาย** | `/admin/orders`, `/admin/products` | Phase 4 |
| **อื่น ๆ** | `/admin/reports`, `/admin/qr`, `/admin/settings` | รายงาน/CSV, พิมพ์ QR, คู่ค้า, ผู้ใช้ |
