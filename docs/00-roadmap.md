# Roadmap (v2)

หลักการ
- **ทำบนเครื่อง (local) จนกว่าจะพร้อม** ยังไม่เสียเงิน
- ข้อมูลรังมีอยู่แล้ว 147 รัง จึง**ทำหลังบ้านและนำเข้าข้อมูลก่อน** แล้วให้หน้าสาธารณะดึงข้อมูลจริงไปแสดง
- ให้ความสำคัญกับ**การขายรังพันธุ์**ก่อน เพราะเป็นรายได้หลักในตอนนี้ (ดู [07-decisions.md](07-decisions.md))

ระยะเวลาประเมินสำหรับคนทำคนเดียวแบบ part-time (ประมาณ 10 ชม./สัปดาห์)

## Phase 2: เว็บสาธารณะ (local)

- [ ] Layout, theme จากโลโก้ (เขียวปาล์ม/เหลืองน้ำผึ้ง), ฟอนต์ไทย, ปุ่ม LINE ลอย
- [ ] หน้าแรก, ชันโรงขนเงิน, น้ำผึ้งชันโรง, งานวิจัย
- [ ] สินค้า: รังสมบูรณ์ (จากฐานข้อมูล), รังเปล่า, น้ำผึ้ง
- [ ] อบรม 2 หลักสูตร (หน้ารายละเอียด + ปุ่มสมัครทาง LINE)
- [ ] **สมุดพกชันโรง**: ค้นหา + หน้ารัง + สายพันธุ์รังแม่/รังลูก
- [ ] ติดต่อเรา, นโยบายความเป็นส่วนตัว
- [ ] SEO: meta, Open Graph, sitemap.xml, structured data (Product, LocalBusiness)

**เสร็จเมื่อ:** Lighthouse มือถือ ≥ 90 ทุกหน้า, ไม่มีข้อมูล 🔒 รั่วไปหน้าสาธารณะ (มี test ตรวจ)

## Phase 3: ขึ้นออนไลน์ (ฟรี)

- [ ] GitHub private repo + CI (lint, typecheck, test, build)
- [ ] สมัครผู้ให้บริการ (ตาม stack) และสร้าง environment `preview` + `production`
- [ ] Migrate + import ข้อมูลจริงขึ้น production
- [ ] Backup อัตโนมัติทุกคืน + ทดลองกู้ข้อมูล 1 ครั้ง
- [ ] Monitoring/analytics
- [ ] เจ้าของฟาร์มใช้งานจริงบนมือถือ

## Phase 4: การขาย

- [ ] ออเดอร์ + ลูกค้า (แอดมินกรอกจากแชต LINE), ขายรังแล้วอัปเดตสถานะรังอัตโนมัติ
- [ ] น้ำผึ้ง: สต็อกต่อขนาด, ล็อตผูกกับการเก็บน้ำหวาน
- [ ] พิมพ์ **QR ติดรัง** (→ สมุดพก) และ **QR บนขวด** (→ ที่มาของล็อต)
- [ ] รายงานยอดขาย/อัตรารอดของรัง, export CSV

## Phase 5: ต่อยอด

- [ ] โดเมนจริง (ประมาณ 400 บาท/ปี), Google Business Profile
- [ ] เพิ่มผู้ใช้ 2–3 คน (role staff)
- [ ] ใช้งานออฟไลน์ในสวน
- [ ] แจ้งเตือนผ่าน LINE
- [ ] โมดูลสวนปาล์ม 50 ไร่

## ความเสี่ยง

| ความเสี่ยง | วิธีรับมือ |
|---|---|
| ข้อมูลใน Excel ไม่สม่ำเสมอ (วันที่หลายรูปแบบ, `AXX`) | import แล้วออกรายงานให้เจ้าของฟาร์มตรวจ ไม่เดาข้อมูล |
| ข้อมูลส่วนตัว (คู่ค้า, ราคาซื้อ) รั่วไปหน้าสาธารณะ | แยก query สาธารณะ/หลังบ้าน + test อัตโนมัติ |
| ข้อความสรรพคุณผิดกฎหมายโฆษณาอาหาร | ใช้ร่างงานวิจัย, ตรวจอ้างอิงก่อนเผยแพร่ |
| การเก็บน้ำหวานเริ่ม 10 ต.ค. ก่อนแอปเสร็จ | จดลง Google Sheet ตามคอลัมน์ที่กำหนด แล้ว import ภายหลัง |
| ข้อมูลหาย | backup ทุกคืนตั้งแต่ Phase 3 และเก็บ Excel ต้นฉบับไว้ |
