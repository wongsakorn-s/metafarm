หลักการ
- **ทำบนเครื่อง (local) จนกว่าจะพร้อม** ยังไม่เสียเงิน
- ข้อมูลรังมีอยู่แล้ว 147 รัง จึง**ทำหลังบ้านและนำเข้าข้อมูลก่อน** แล้วให้หน้าสาธารณะดึงข้อมูลจริงไปแสดง

## ความเสี่ยง

| ความเสี่ยง | วิธีรับมือ |
|---|---|
| ข้อมูลใน Excel ไม่สม่ำเสมอ (วันที่หลายรูปแบบ, `AXX`) | import แล้วออกรายงานให้เจ้าของฟาร์มตรวจ ไม่เดาข้อมูล |
| ข้อมูลส่วนตัว (คู่ค้า, ราคาซื้อ) รั่วไปหน้าสาธารณะ | แยก query สาธารณะ/หลังบ้าน + test อัตโนมัติ |
| ข้อความสรรพคุณผิดกฎหมายโฆษณาอาหาร | ใช้ร่างงานวิจัย, ตรวจอ้างอิงก่อนเผยแพร่ |
| การเก็บน้ำหวานเริ่ม 10 ต.ค. ก่อนแอปเสร็จ | จดลง Google Sheet ตามคอลัมน์ที่กำหนด แล้ว import ภายหลัง |
| ข้อมูลหาย | backup ทุกคืนตั้งแต่ Phase 3 และเก็บ Excel ต้นฉบับไว้ |
