## 🔒 กฎและข้อปฏิบัติสากลในโปรเจกต์ (Core Conventions)

1. **ข้อมูลลับ 🔒 (Strictly Confidential):**
   * ฟิลด์ที่มีเครื่องหมาย 🔒 ใน [03-data-model.md](03-data-model.md) ได้แก่ ราคาซื้อ, ชื่อคู่ค้า, รายชื่อลูกค้า และบันทึกส่วนตัว จะต้องไม่ถูกส่งไปยัง Client ในหน้าสาธารณะเป็นอันขาด (ตรวจสอบอัตโนมัติด้วย `npm run check:leaks`)
2. **การแสดงผลวันที่:**
   * ฐานข้อมูลจัดเก็บในรูปแบบสากล ISO `YYYY-MM-DD`
   * การแสดงผลภาษาไทยจะแปลงเป็นปี พุทธศักราช (พ.ศ.) ผ่าน `src/lib/thai-date.ts`
3. **การแก้ไขเนื้อหาหน้าเว็บ:**
   * เนื้อหาบทความทั่วไปสามารถแก้ไขได้ในโฟลเดอร์ [`content/`](../content/) ซึ่งรองรับรูปแบบ Markdown
