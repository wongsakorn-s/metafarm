# 🎨 ทรัพยากรการออกแบบ (Design Assets)

โฟลเดอร์นี้จัดเก็บไฟล์งานออกแบบ โลโก้ และภาพร่างของโปรเจกต์ MetaFarm

---

## 📂 โครงสร้างโฟลเดอร์

* **`logo/`**: ไฟล์ต้นฉบับโลโก้ MetaFarm (SVG และ PNG ความละเอียดสูง)  
  *แปลงเป็นไฟล์เว็บและ Favicon อัตโนมัติด้วยคำสั่ง `npm run brand:build`*
* **`wireframes/`**: ภาพร่างโครงสร้างหน้าจอ
* **`colors.md`**: บันทึกชุดสีและคู่สีดั้งเดิม

> [!NOTE]
> สำหรับ **Design System ฉบับสมบูรณ์ (Master Tokens, Spacing, Icons, กฎ UX/UI)**  
> ให้อ้างอิงที่ [**`design-system/metafarm/MASTER.md`**](../design-system/metafarm/MASTER.md) เป็นหลัก
